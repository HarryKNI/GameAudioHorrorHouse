# GameAudioHorrorHouse

# Introduction
This project explores the different sounds that can be implemented within a game. Being paired into groups we will learn to implement Fmod into unity, record our own sounds and put them into the games we have. There will be audio students and game students mixed into the groups in order for us to learn both skills.

# Objectives and Motivation

* Improve the ability to add more detailed audio in games within unity
* Using Fmod 
* Working in Unity
* Record Audio

# Technology and Tools

* Unity
* FMod
* Reaper
* Visual Studio Code

# Game Summary
The lore is that mamud decides to go to harrys house to finally pay the £3.50 but what he doesnt realise is that harry has been infected and once he enters that house there is no escape.
